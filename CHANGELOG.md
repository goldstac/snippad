# Change Log

All notable changes to SnipBase will be documented in this file.

## `v0.1.0` - 2026-08-13

### Initial Release

#### Core Features

- Snippet and Tag Management: Unlimited snippet and tag creation with filtered listing support.
- Editor Workspace: Integrated bundled Monaco Editor for code editing.
- Interactive Panel:
  - Action Row: Quick actions for saving, editing, starring, and deleting snippets.
  - File Tabs: Tabbed navigation for viewing and switching between active snippet files.

#### Customization & Config

- Custom Theme Support (`~/.snipbase/themes.json`):
  - Client Themes: Customize UI theme colors.
  - Editor Themes: Custom Monaco Editor themes support.
- Custom Settings (`~/.snipbase/settings.json`): Configurable options for application behavior and editor preferences.

#### System

- Auto-Updates: Automated update checks to deliver the latest features and patches.
